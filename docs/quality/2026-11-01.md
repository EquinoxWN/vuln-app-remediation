# Quality check against the 10 rules (2026-11-01)

Run on 2026-11-09 on Windows 11 (Intel Core i7-13700H) with Python 3.14.5 in the repo's `.venv`.
The app is intentionally vulnerable: the rules apply to everything *around* the catalogued flaws
(guards, fixtures, CLI, tests). The catalogued flaws themselves are the product and stay in place.
Mutations were applied one at a time by a script that restored each file in a `finally` block; the
suite was green (35 passed) after the run.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | The only external call, the preview fetch, has a 3 s timeout and a 64 KB read cap; `URLError`, `ValueError` and `OSError` become a 502, not a 500 (tested). SQLite errors in login become 401. No bare `except`, no swallowed errors in `src/`. |
| 2 | Writes safe to retry | pass | The only write is the profile `UPDATE` (idempotent for the same body). No files are written by the app or CLI. |
| 3 | No race conditions | pass | One in-memory DB per request (or one injected per test); no shared mutable globals. Flask's dev server is single-process. |
| 4 | Don't trust the clock | N/A | No durations or stored times; nothing reads the clock. |
| 5 | Read before changing | pass | Env vars `VULN_APP_I_UNDERSTAND` and `VULN_APP_PORT` are documented in the README. Every README link is checked by `audit_repo.py`. |
| 6 | Never break compatibility | pass | First release; route paths are listed in `catalog.FLAWS` and pinned by the tests. |
| 7 | One source of truth | pass | `catalog.FLAWS` drives `/api/flaws`, the CLI, the write-up test and the exploit guard test. |
| 8 | Small changes, no secrets, validate input | fixed | Secret grep: only `EXAMPLE-NOT-A-SECRET` fixtures. `VULN_APP_PORT` was parsed with a bare `int()` (traceback on bad input); it is now checked to be an integer in 1024..65535 and exits 2 otherwise (5 parametrised tests). Order ids, required fields and JSON bodies are validated. |
| 9 | Tests that can actually fail | pass | Each exploit test checks a baseline before the exploit; guard tests cover empty, invalid and anonymous paths. 8/8 hand mutants killed. |
| 10 | Re-verify | pass | Results below; CI on push (including the no-network container job). |
